# Saeid Engine

Interactive 3D automotive mechanics learning lab built with Three.js.

## Features
- Procedural 3D sports-car cutaway model
- Transparent/X-Ray engine bay
- Interactive engine internals: pistons, rods, crankshaft, turbochargers
- Transmission and differential
- Disc brakes and independent suspension
- Rack-and-pinion steering
- Exhaust and cooling systems
- Click-to-learn component information
- Exploded-view mode
- Orbit, zoom, focus and auto-rotate controls
- Responsive desktop/mobile UI
